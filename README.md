## ◆ Como executar

**1. Clonar o repositório**

```bash
git clone https://github.com/SEU_USUARIO/NOME_DO_REPOSITORIO.git
cd NOME_DO_REPOSITORIO
```

**2. Criar e ativar o ambiente virtual**

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

**3. Instalar dependências (se houver)**

```bash
pip install -r requirements.txt
```

**4. Executar um arquivo**

```bash
python caminho/do/arquivo.py
```

## ◆ Padrões adotados

- ▸ Código seguindo a [PEP 8](https://peps.python.org/pep-0008/).
- ▸ Nomes de variáveis e funções em `snake_case`.
- ▸ Docstrings e *type hints* nas funções.

### Convenção de commits

| Prefixo     | Uso                                  |
| ----------- | ------------------------------------ |
| `feat:`     | Nova atividade adicionada            |
| `fix:`      | Correção em uma atividade existente  |
| `docs:`     | Mudanças no README ou comentários    |
| `refactor:` | Reorganização sem alterar o resultado|

Exemplo: `feat: adiciona atividade de laços de repetição`
